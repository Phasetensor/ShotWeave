ShotWeave allocates a fixed shot budget across independent binary measurement circuits using uniform, coefficient-weighted or adaptive allocation.

- Run experiments through a Python callback or the optional Qiskit V2 sampler adapter.
- Estimate weighted sums from recorded counts with the CLI and compute confidence intervals through the Python API.
- Reproduce the seeded benchmarks comparing fixed and automatic pilot sizes.

Install with `python -m pip install shotweave==0.1.0`.

[PyPI package](https://pypi.org/project/shotweave/0.1.0/)
